## Key Stats

Numbers from the peer-reviewed research above, so every one has a source.

- **4x** more sales from undisclosed AI sales bots than from inexperienced reps; upfront disclosure cut purchases ~80% ([Luo et al., 2019](https://doi.org/10.1287/mksc.2019.1192))

- **Junior-to-mid rep level** is where today's best LLMs land on realistic selling benchmarks, not expert level ([Su et al., EMNLP 2026](https://aclanthology.org/2026.emnlp-main.974/))
